# 기능

DCRefresher Reborn이 제공하는 다양한 기능을 설명합니다.

- [컨텐츠 차단](./features/block.md) — 유저, 컨텐츠 등 보고 싶지 않은 컨텐츠를 삭제합니다.
- [폰트 교체](./features/fonts.md) — 페이지에 표시되는 폰트를 교체합니다.
- [이미지 검색](./features/imagesearch.md) — 이미지의 출처를 검색합니다.
- [레이아웃 수정](./features/layout.md) — 디시 레이아웃을 변경할 수 있도록 도와줍니다.
- [관리](./features/manage.md) — 갤러리 관리를 위한 여러 편의 기능을 제공합니다.
- [미리보기](./features/preview.md) — 글을 오른쪽 클릭하면 미리보기 창을 띄워줍니다.
- [글 목록 새로고침](./features/refresh.md) — 글 목록을 자동으로 새로고침합니다.
- [스텔스 모드](./features/stealth.md) — 페이지 내 이미지를 숨깁니다.
- [유저 정보](./features/userinfo.md) — 사용자의 IP, 아이디 정보, 메모를 표시합니다.
- [글쓰기](./features/write.md) — 글쓰기 페이지에 편의 기능을 추가합니다.
